# 🌐 Website WireFrame Project

> A student-level website wireframe created to demonstrate the basic structure, layout, and design of a personal portfolio webpage using HTML5 and CSS3.

---

## 📌 About the Project

This project is a **Website WireFrame Project** designed as a basic layout of a personal portfolio website.

The main focus of this project is to understand how different HTML elements and CSS properties can be combined to create the structure of a webpage.

The wireframe includes multiple sections such as an introduction, about section, skills, projects, education, certified courses, contact information, and footer.

---

## 🎯 Project Objective

The main objectives of this project are:

* To understand the basic structure of an HTML webpage.
* To practice HTML5 tags and elements.
* To understand basic CSS styling.
* To create a structured webpage layout.
* To work with tables, lists, images, buttons, and text.
* To organize website content into different sections.
* To understand how a portfolio-style webpage can be structured.

## ▶️ How to Run the Project

Download or copy the complete project folder.

### Step 2

Make sure the `asset` folder is located in the same directory as `index.html`.

### Step 3

Open the `index.html` file in a web browser.

### Step 4

The complete website wireframe will appear in the browser.
